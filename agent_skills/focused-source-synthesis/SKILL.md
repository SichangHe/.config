# Focused Source Synthesis

Tie every important claim to source text.

## Source Choice

- Prefer official, primary, or authoritative sources.
- Use secondary sources only when they add necessary context or reveal disagreement.
- For web research, search current sources when the fact may have changed.

## Reading

- Identify the user's focus before summarizing.
- Extract every source point that bears on that focus.
- Quote the exact original phrase, sentence, or short passage for each point.
- Keep quotes short and compliant.
- Preserve uncertainty, scope limits, population, assumptions, and methods.

## Output

- Separate fact, claim, inference, and uncertainty.
- Provide source pointers with each quoted or paraphrased point.
- Avoid broad claims when the source only supports a narrow one.
- If sources disagree, explain the disagreement before synthesizing.
