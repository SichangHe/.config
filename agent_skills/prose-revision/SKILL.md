# Prose Revision

Improve the text without replacing the author's intent.

## Critique

- Quote the original words for each problem.
- Explain the concrete issue.
- Suggest a change.
- Provide a minimal replacement only when useful.
- Avoid praise, filler, and repeated points.

## Compression

- Preserve all information.
- Stay close to the original language and order.
- Prefer verbs over nouns and adjectives over adverbs.
- Prefer active voice when it is clearer.
- Remove repetition, hedging, and self-judgment.
- Keep the result natural, complete, and as short as possible.

## Prompt Repair

- When the user dislikes a model response, infer which instruction was missing or weak.
- Write the prompt wording that would have prevented the unwanted behavior.
- Make the prompt specific, strong, and testable.
