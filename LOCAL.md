# Local config

These files are intentionally local because they contain machine-specific absolute paths, device IDs, ports, or runtime state.

- `omo_manager/local.env`: copy `conf_template/omo_manager/local.env` and set `OMO_WORK_LOGS_ROOT` to the markdown work-log checkout, plus the manager URL and private state paths for this machine. Keep state/mail under a user-private directory such as `$XDG_STATE_HOME/omo-manager`.
- `opencode/tui.json`: copy `conf_template/opencode/tui.json` and point plugin entries at the local built plugin files.
- `browser-use-opencode/config.json`: copy `conf_template/browser-use-opencode/config.json` and set the CDP URL and downloads directory for the local browser profile.
- `browser-use-opencode/device_id`: generated by browser-use-opencode; do not copy between machines.

Email watching is optional. Set `OMO_MANAGER_ENABLE_EMAIL_WATCHER=true` or leave it as `auto` with a valid `OMO_EMAIL_CONFIG_PATH`; the current watcher expects a Himalaya TOML account whose IMAP host/login and password command can be parsed locally.
