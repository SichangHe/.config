# Local config

These files are intentionally local because they contain machine-specific absolute paths, device IDs, ports, or runtime state.

- `amh/local.env`: copy `conf_template/amh/local.env` and set `OMO_WORK_LOGS_ROOT` to the markdown work-log checkout, plus the main manager's agent address, the agent Gmail account, and the human's email address. Guest mailbox keys `AMH_GUEST_ADDRESS`, `AMH_GUEST_WORKDIR`, and `AMH_GUEST_MAIL_PREFIX` are optional.
- `opencode/tui.json`: copy `conf_template/opencode/tui.json` and point plugin entries at the local built plugin files.
- `codex/agents/reviewer.toml`: copy `conf_template/codex/agents/reviewer.toml` to `$CODEX_HOME/agents/reviewer.toml` or `~/.codex/agents/reviewer.toml` to install the read-only Codex reviewer.
- `browser-use-opencode/config.json`: copy `conf_template/browser-use-opencode/config.json` and set the CDP URL and downloads directory for the local browser profile.
- `browser-use-opencode/device_id`: generated by browser-use-opencode; do not copy between machines.

The watcher runs as the user systemd unit `amh/amh-watch.service`, linked from `systemd/user/`; restart it with `amh manager watchers`.
