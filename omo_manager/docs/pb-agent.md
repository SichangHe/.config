# PB agent manager usage

Use this for manager handling of PB watcher, PB digest, and PB runtime handoff reports.

Routine closeouts:
- PB watcher digest/runtime handoff closeouts are routine non-email bookkeeping
- record routine closeouts in markdown

Human email:
- email the human when the PB agent reports genuine urgency
- email the human when PB reports an action or blocker needing the human
- email the human when a separate human request asks about PB work
